# Architecture Decision Records

An ADR captures **one significant decision**: the context, the choice, the
alternatives rejected, and the consequences. They are short and, once accepted,
immutable — if a decision changes we add a new ADR that supersedes the old one
rather than editing history.

Each record has: **Status** (proposed / accepted / superseded), **Context**,
**Decision**, **Alternatives**, **Consequences**.
